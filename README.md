# Quiz Game 🎯

A responsive, browser-based quiz application built with **HTML, CSS, and JavaScript**. The project demonstrates core front-end development concepts including DOM manipulation, event handling, dynamic UI generation, state management, and conditional logic.

## 📌 Overview

Quiz Game allows users to answer a series of multiple-choice questions and receive their final score after completing the quiz.

The application was built to strengthen practical understanding of JavaScript by connecting **HTML structure, CSS styling, and JavaScript logic** into an interactive web application.

## ✨ Features

* Start quiz from an interactive welcome screen
* Multiple-choice questions
* Dynamically generated answer buttons
* Immediate visual feedback for correct and incorrect answers
* Score tracking
* Question progress tracking
* Automatic navigation between questions
* Final score/result screen
* Restart quiz functionality
* Responsive layout for different screen sizes

## 🔄 How It Works

The application follows a simple quiz flow:

```text
Start Screen
     ↓
Start Quiz
     ↓
Display Question
     ↓
Generate Answer Options
     ↓
Select Answer
     ↓
Check Answer
     ↓
Update Score
     ↓
Next Question
     ↓
More Questions?
   ↙       ↘
 Yes       No
  ↓         ↓
Next      Results
Question    ↓
            ↓
       Restart Quiz
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Dnyandaa18/Quiz-Game.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd Quiz-Game
```

### 3. Run the application

Open `index.html` in a web browser.
No external dependencies or installation steps are required.

## 🎮 How to Use

1. Open the application.
2. Click **Start Quiz**.
3. Read the displayed question.
4. Select one of the available answers.
5. The application checks the selected answer and updates the score.
6. Continue through all questions.
7. View the final score.
8. Click **Restart Quiz** to play again.
